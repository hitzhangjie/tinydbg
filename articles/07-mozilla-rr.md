# 7. 基于mozilla rr的确定性调试设计与实现

## 7.1 mozilla rr简介

mozilla rr 是一款开源的 Linux 下用户态进程记录与重放工具，支持对程序执行过程的全程录制和确定性重放，广泛用于调试、回归测试和故障定位。

## 7.2 确定性调试的基本原理

- **录制（record）**：rr 拦截并记录目标进程的所有系统调用、信号、线程调度等非确定性事件，生成完整的执行日志。
- **重放（replay）**：在重放阶段，rr 精确复现录制时的所有外部输入和调度顺序，实现逐指令级的确定性调试。
- **调试集成**：rr 提供与 gdb 等调试器的集成接口，支持在重放过程中任意位置断点、单步、回溯、逆向执行等高级调试操作。

## 7.3 典型实现流程

1. 启动 rr 录制：`rr record <target-program> [args...]`
2. 目标程序运行，rr 记录所有非确定性事件。
3. 录制结束后，使用 rr 重放：`rr replay`
4. 在 replay 会话中，调试器（如 gdb）可 attach 到 rr，进行断点、单步、逆向调试等操作。

## 7.4 关键技术点

- **系统调用拦截与记录**：通过 ptrace、seccomp 等机制拦截所有系统调用，记录输入输出。
- **线程调度控制**：强制线程调度顺序一致，避免并发非确定性。
- **信号与异步事件重放**：精确重现信号、定时器等异步事件。
- **高效存储与回放**：采用增量存储和高效索引，支持大规模程序的长时间录制与快速回放。

## 7.5 优缺点

**优点：**
- 支持逐指令级的逆向调试和回溯，极大提升疑难 bug 定位能力。
- 彻底消除并发、异步等非确定性因素，保证调试结果可复现。
- 与 gdb 等主流调试器无缝集成，学习成本低。

**缺点：**
- 仅支持 Linux 平台，且对内核版本有一定要求。
- 录制和重放过程有一定性能开销，部分高性能场景下不适用。
- 对部分系统调用、硬件特性支持有限。

## 7.6 小结

mozilla rr 为确定性调试提供了完整的技术方案，适合定位复杂并发、异步、偶现性 bug，是现代调试器体系的重要补充。
