# LLM Debug Demo 2 - Automated Debugging with LLM + Debugger I/O Redirection

## Overview

This is a practical demonstration of **automated debugging powered by LLM (Large Language Model)** combined with **debugger I/O redirection**. 

The key idea: instead of asking humans to manually interact with the debugger, we use an AI Agent to automatically generate debugging commands based on the current debugger output, implement the ReAct (Reasoning + Acting) loop, and progressively locate bugs.

```bash
# Run automated debugging using pre-prepared commands from stdin.txt
/home/zhangjie/debugger101/tinydbg/tinydbg exec ./main --allow-non-terminal-interactive < stdin.txt > stdout.txt 2> stderr.txt
```

```bash
# See the command sequence

```

## Problem Description

**File**: `main.go`

**Bug**: Loop condition uses `<=` instead of `<`, causing index out of bounds access.

```go
for i := 0; i <= len(a); i++ {  // Wrong: should be i < len(a)
    sum += a[i]  // When i=5, a[5] exceeds array bounds
}
```

**Expected Symptom**: `panic: runtime error: index out of range [5] with length 5`

## Debugging Strategy

The AI Agent follows this ReAct reasoning loop:

1. **Observe**: Current debugger state (location, variables)
2. **Reason**: What do I need to know? What's the next hypothesis?
3. **Act**: Send appropriate debugger command (break, step, print, continue)
4. **Learn**: Analyze output to refine understanding
5. **Decide**: Bug found or need more steps?

## Execution Flow Summary

### Phase 1: Initialization
```
break main.main
continue
→ Program stops at main entry point
```

### Phase 2: Variable Discovery (fails initially)
```
print a
→ Error: could not find symbol value for a (not initialized yet)
```

**Lesson**: Must step forward to initialize variables.

### Phase 3: Step and Initialize
```
step
print a
→ Success: a = []int len: 5, cap: 5, [1,2,3,4,5]
```

### Phase 4: Loop Iteration Monitoring
```
step (multiple times)
print i
→ i = 0, 1, 2, 3, 4 (normal iterations)
```

### Phase 5: Anomaly Detection
```
continue
→ Unrecovered panic: runtime error: index out of range [5] with length 5
```

**Diagnosis**: Loop goes beyond array bounds. Condition should be `i < len(a)`.

### Phase 6: Exit
```
exit
→ Debugging session complete
```
